# Lotus & Lime – landingspagina

Landingspagina voor **Lotus & Lime**, een fictief theemerk uit de periodeopdracht *Creative Automations* (Arteveldehogeschool, DVG2B – Matteo Colameo).

- **Hero**: "Frisdrank? *Nah.*" met de 4 doosjes
- **Verhaal**: waarom ijsthee i.p.v. frisdrank + 3 stappen (zet, koel, ijs erbij)
- **Smaken**: 4 kaarten, elk met een eigen moment en Firefly-beeld
- **Video**: campagnevideo (15 s)
- **CTA**: ingebed MailerLite-formulier (voornaam, e-mail, favoriete smaak, opt-in) → start de welkomstflow
- **Footer**: GDPR en AI-transparantie

## Automatisatie
Elke push naar `main` start `.github/workflows/deploy.yml`, die de site automatisch publiceert op GitHub Pages.

## Tools
Gebouwd met Claude Code. Beelden: Adobe Firefly + Photoshop. Copy: Claude. Formulier: MailerLite.
